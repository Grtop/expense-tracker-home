# Инструкция по настройке Better DeepSeek (BDS) в Firefox

Расширение **Better DeepSeek** добавляет мощные инструменты для работы с DeepSeek: создание файлов, визуализации, генерацию презентаций, работу с памятью и многое другое. Ниже приведено полное описание всех пунктов настроек с пояснениями, как и когда их менять.

---

## 1. Общие настройки (General Settings)

### 1.1. Hidden System Prompt (Скрытый системный промпт)
Расширение внедряет свой системный промпт, который управляет поведением BDS (инструменты, протоколы).  
**По умолчанию:** включён.  
**Совет:** не отключайте, иначе инструменты (создание файлов, визуализатор и др.) перестанут работать корректно.

### 1.2. Advanced Settings (Расширенные настройки)
Раскрывающийся блок с дополнительными параметрами (см. ниже).

---

## 2. Расширенные настройки (Advanced Settings)

### 2.1. Auto download create_file outputs  
Автоматически скачивать файлы, созданные через `<BDS:create_file>` (если они не упакованы в ZIP).  
**Рекомендация:** включите, если вы часто запрашиваете отдельные файлы — они будут сохраняться сразу без лишних кликов.

### 2.2. Disable Hidden System Prompt  
Полное отключение встроенного системного промпта (опасно).  
**Не включайте** без крайней необходимости — вы потеряете все возможности BDS.

### 2.3. Disable Stored Memory Injection  
Отключает внедрение сохранённой памяти (ключей `memory_write`) в контекст диалога.  
**Оставьте выключенным**, если хотите, чтобы расширение запоминало ваши предпочтения, имя, проекты между сессиями.

### 2.4. System Prompt Injection Frequency  
Частота внедрения системного промпта.  
- **Only on first message** (только в первом сообщении) — экономит токены, но последующие сообщения могут терять контекст инструментов.  
- **Каждое сообщение** — надёжнее, но дороже.  
**Рекомендация:** оставьте `Only on first message`.

### 2.5. Voice Mode (Auto-read responses)  
Автоматическое озвучивание ответов DeepSeek голосом.  
**Включите,** если хотите прослушивать ответы.

### 2.6. Auto-submit after speech  
Автоматически отправлять сообщение после окончания голосового ввода.  
**Включите,** если используете голосовой ввод — не придётся нажимать кнопку отправки.

### 2.7. Speech Language  
Язык синтеза речи. Доступен `English (US)`, возможно добавление других.  
**Выберите** подходящий вам язык.

### 2.8. Auto download LONG_WORK zip  
Автоматически скачивать ZIP-архив после завершения режима `<BDS:LONG_WORK>` (когда создаётся 3+ файла).  
**Рекомендуется включить** — вы не пропустите готовый проект.

---

## 3. Настройки ответов и обработки контента

### 3.1. Preferred Response Language (Предпочитаемый язык ответов)  
Можно задать `Russian` (русский) или оставить пустым — тогда модель выбирает сама.  
**Совет:** укажите `Russian`, если хотите стабильно получать ответы на русском.

### 3.2. Markdown Walker Max Depth  
Максимальная глубина рекурсии при преобразовании DOM сообщения в Markdown.  
- Значение по умолчанию: `200`.  
- Уменьшайте (например, до 50), если при обработке длинных вложенных сообщений возникает ошибка переполнения стека.  
- Увеличивайте только при работе с патологически вложенными данными.  
**Оставьте 200** для большинства сценариев.

### 3.3. Chat Session List Cap  
Максимальное количество сессий чата, хранящихся в боковой панели. Старые сессии удаляются (FIFO).  
- По умолчанию: `500`.  
- Уменьшите (например, до 100), если замечаете высокое потребление памяти в долгоживущей вкладке.  
- Увеличьте, если вам нужно много истории.

---

## 4. GitHub и оценка стоимости токенов

### 4.1. GitHub Personal Access Token  
Персональный токен доступа GitHub с областью `repo`. Используется для работы с репозиториями (например, `<BDS:AUTO:REQUEST_GITHUB_FETCH>`).  
**Как получить:** GitHub Settings → Tokens → Generate classic token → выбрать scope `repo`.  
**Совет:** создайте токен и вставьте сюда — тогда расширение сможет читать приватные репозитории и увеличит лимиты запросов.

### 4.2. Token Price Estimation (Experimental)  
Оценочная стоимость запросов к DeepSeek API (цена за токены ввода/вывода). Данные загружаются динамически.  
**Можно включить** для контроля расходов, но учтите — это экспериментальная функция.

### 4.3. Save Settings  
Кнопка сохранения всех изменённых настроек. **Не забудьте нажать** после того, как всё настроили.

---

## 5. Навыки (Skill Set)

### 5.1. Upload Skill (.md)  
Загрузка файла навыка в формате Markdown. Навыки расширяют возможности ассистента (специализированные инструкции, знания).  
**Как использовать:** подготовьте `.md` файл с описанием навыка и загрузите.  
**Статус:** `No skills loaded` — пока не загружено ни одного навыка.

---

## 6. Ролевые персонажи (RP Characters)

### 6.1. Upload Persona (.md)  
Загрузка файла персонажа (Persona) для ролевых игр. Содержит описание характера, манеры речи, фона.  
После загрузки персонаж появится в списке. Выбрать активного можно через интерфейс (пункт `None (Assistant)` — значит, активен обычный ассистент).  
**Статус:** `No personas saved` — персонажи не сохранены.

---

## 7. Сохранённая память (Stored Memory)

Здесь отображаются факты, которые расширение запомнило через тег `<BDS:memory_write>`.  
**Примеры:** ваше имя (`user_name`), предпочитаемый язык, текущий проект.  
Память работает между сессиями. Если записей нет — отображается `No memory entries yet`.  
**Управление:** записи можно удалять вручную (интерфейс).

---

## 8. Проекты (Projects)

Эта область находится под полем ввода чата (не в модальном окне настроек). Позволяет выбирать текущий проект и файлы из него для контекста.  
**Использование:** полезно, когда вы работаете над большим проектом и хотите, чтобы ассистент видел структуру файлов.

# Рекомендуемый профиль настроек для обычного пользователя

| Параметр | Значение |
|----------|----------|
| Hidden System Prompt | Включён (не отключать) |
| Auto download create_file outputs | ✅ Включить |
| Disable Stored Memory Injection | ❌ Выключить |
| System Prompt Injection Frequency | Only on first message |
| Voice Mode | По желанию |
| Auto download LONG_WORK zip | ✅ Включить |
| Preferred Response Language | Russian |
| Markdown Walker Max Depth | 200 |
| Chat Session List Cap | 500 |
| GitHub Token | Вставить, если нужно |
| Token Price Estimation | ❌ Выключить (эксперим.) |

После изменения любых параметров нажмите **Save Settings**.
